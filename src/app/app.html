    Add a page by its address

    Easier: open the page, click the Heron button in the toolbar and choose “Watch one part”.

    Firefox will ask once to let Heron read that site.

    Settings

    Firefox asks for permission to show notifications when you switch this on. Heron uses them for changes only. The number on the toolbar button always shows how many watches have something new.

    Export and import

    The file holds each watch's name, address, part and interval. Saved page text is not exported.

    What Heron can and can't see

    • It reads the HTML the server sends. Checks run in the background without opening the page, so nothing a page draws later with JavaScript is seen. If you pick such a part, Heron tells you right away instead of watching nothing.
    • It checks without your cookies. Heron sees what a signed-out visitor sees, so pages behind a sign-in can't be watched. That is on purpose: a background check that used your sign-in could act on your account, and private pages would end up in the saved versions.
    • It compares text. A change in pictures, layout or styling alone is not reported.
    • It runs while Firefox is open. Checks that were due while Firefox was closed are done when it starts again.
    • It is gentle on sites. The shortest interval is 5 minutes, and watches on the same site are checked one after another. Some sites still refuse automatic requests; those watches show “Blocked”.
    • It keeps storage small. Up to 200 watches, the last 10 versions of each, and the first 100,000 characters of a page.

    Everything stays in this browser: no account, no server, nothing uploaded. The only requests Heron makes go straight to the pages you watch.
